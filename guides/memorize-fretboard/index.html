ギター指板の音の覚え方：開放弦から11段階で進める目安

指板の音は、6本の開放弦の音名から始め、6弦と5弦のナチュラル音（♯・♭の付かない音）、5フレットとオクターブの形の順に覚えます。各段階は、目印なしの10問で9問以上正解し、平均回答時間が目標（多くの段階で2.5秒）以内に収まったら次へ進む目安です。

この記事の段階・目標の数値は、指板トレーナーの学習マップの設定値をそのまま載せています。

指板トレーナーを開く 無料・ブラウザで使える

指板が覚えにくい理由

標準チューニングの開放弦は、6弦から順に E・A・D・G・B・E です。隣り合う弦はほとんどが5フレット分ずれていますが、3弦と2弦の間だけは4フレット分です。

音名は C・D・E・F・G・A・B の7つで、E と F、B と C の間だけが1フレット、ほかは2フレット離れています。そのため同じ音名でも、弦ごとにフレットの数え方が変わります。指板全体を一度に覚えようとせず、範囲を区切って1つずつ法則を足していくほうが迷いません。

覚える順番（11段階）

指板トレーナーの学習マップは、音名の6段階と度数の5段階、合わせて11段階です。段階にロックは無く、どこからでも始められます。各段階の秒数は、目印なしの10問で目指す平均回答時間です。

目印にするフレット

12フレット

12フレットは開放弦と同じ音名に戻ります（1オクターブ上）。7フレットより上の音は、開放から数えるより12フレットから左へ数えたほうが近道です。

5フレット

5フレットの音は、細い隣の弦の開放音と同じです。たとえば6弦の5フレットは A で、5弦の開放と同じ音名です。例外は3弦で、2弦の開放 B と同じになるのは4フレットです。

E-F と B-C

ナチュラル音どうしで1フレットしか離れていないのは、E と F、B と C の2か所だけです。6弦と1弦は開放が E なので、1フレットがすぐ F になります。

正解率と回答時間で進み具合を見る

各段階は、覚え方を読む、目印を見ながら3問、目印を消して10問、の3ステップで進みます。目印なしの10問で9問以上正解し、平均回答時間が段階ごとの目標以内ならクリアです。学習マップにはどの段階も「目標 90%」と、その段階の目標の時間が出ます。

普段のクイズの記録でもクリアになります。範囲内のマスの9割で、3回以上答えていて、正解率9割以上、平均が目標の時間以内なら、その段階はクリアとして扱われます。

ホームと成績に出る指板の習熟度（0〜100）は、正解率・回答時間・最後に答えた日・回答回数から計算します。回答時間は、平均1.2秒以下なら速さを満点、4秒以上なら速さを0として数えます。

1回の練習の進め方

  1. 学習マップで段階を1つ選びます。「次はここ」の表示は、まだクリアしていない最初の段階に付きます。
  2. 覚え方の文と指板の図で、その段階の法則を1つだけ確かめます。
  3. 目印を見ながら3問答えます。
  4. 目印を消して10問答えます。間違えると、正解に加えて法則と、知っている音からの道筋（開放 E から数える、など）が出ます。
  5. 9問以上正解して平均が目標の時間以内なら次の段階へ、届かなければ同じ段階をもう一度解きます。

音名の次は度数へ

7〜11段階は度数です。指板にルート（基準にする音）の位置が出て、そこから見た度数を答えます。5度とオクターブ、4度、3度の順に、細い隣の弦のどこにあるかという形で覚えます。最後の段階では、3弦と2弦の間で形が1フレット右にずれる例外をまとめて練習します。

音名と度数が指板でつながったら、聴いた音を指板のどこで弾くかを探す耳コピ練習に進めます。

よくある質問

何日で覚えられますか？
人によって違うため、この記事では日数の目安を出していません。各段階の目標（目印なしの10問で9問以上正解し、平均が目標の時間以内）を満たしたら次へ進んでください。
ナチュラル音だけ覚えれば足りますか？
♯ と ♭ は、ナチュラル音の1フレット右が ♯、左が ♭ です。ナチュラル音の位置が分かれば導けます。同じ場所に2つの名前があることも含めて、6段階目の「シャープとフラット」で練習します。
指板の図を眺めるのと何が違いますか？
図では答えが見えたままです。指板トレーナーは位置を出して音名を答えさせ、1問ごとに回答時間を計ります。苦手なマスは成績のヒートマップで確かめられます。
