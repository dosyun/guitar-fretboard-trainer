Cコードの押さえ方：指板図と、各弦で鳴る音・6弦の扱い

F G C D

Cコードは、薬指で5弦3フレット、中指で4弦2フレット、人差し指で2弦1フレットを押さえ、3弦と1弦は開放で鳴らします。6弦は親指で軽く触れてミュートします。

構成音は C（ド）・E（ミ）・G（ソ）の3つです。

各弦で鳴る音名と度数は、押さえるフレットから計算しています。指板図は上が1弦、左端がナット（0フレット）で、丸の中の数字は押さえる指（1 人差し指・2 中指・3 薬指・4 小指・親 親指）、右端の文字はその弦で鳴る音です。

Cコードの構成音

Cコード（Cメジャー）は、C（ド）・E（ミ）・G（ソ）の3つの音でできています。ギターではこの3つを6本の弦に割り振り、同じ音名の音を高さを変えて2回以上鳴らすこともあります。

基本の形

弦押さえる場所指鳴る音度数
6弦鳴らさない—×（ミュート）—

6弦は押さえずに、親指の先で軽く触れて音を止めます。

鳴らさない弦を鳴らしてしまったとき

「基本の形」で鳴らさない弦を、うっかり開放のまま鳴らしたときに出る音です。

弦開放で鳴る音Cコードとの関係
6弦E（ミ）構成音（長3度）。鳴ってもコードはCのまま、いちばん低い音がミになる

1本ずつ鳴らして確かめる

コードがきれいに鳴らないときは、弦を1本ずつ弾いて、どの弦の音が出ていないかを探します。

  1. 「基本の形」で押さえます。
  2. 6弦から1弦へ、1本ずつ弾きます。鳴るはずの音は 6弦 ×・5弦 C・4弦 E・3弦 G・2弦 C・1弦 E です（× は音が出ないのが正しい弦）。
  3. チューナーを使うなら、音名を表示するクロマチックチューナーで、各弦の表示が上の音名と同じかを見ます。
  4. 音が詰まる弦があれば、その弦を押さえている指（表の「指」）を見直します。開放で鳴らす弦が詰まるときは、隣の弦を押さえている指が触れていないかを見ます。

1か所変えると別のコードになる

「基本の形」から1本の弦だけを変えると、Cの3つの音に1つ音が加わるか入れ替わり、別の名前のコードになります。

指板の上で構成音を探す

指板トレーナーの「理論」→「オープン」では、C・D・G など開放弦を使うコードの押さえ方を、音名と度数の表示を切り替えて見られます。押さえる形を覚えたら、どの弦が何の音かを指板の上で確かめると、ほかのコードの形も読みやすくなります。

よくある質問

6弦を鳴らしてしまったら、コードが変わりますか？
6弦の開放は E（ミ）で C の3度なので、鳴っても C のままです。ただし、いちばん低い音が C からミに変わります。6弦3フレット（G・ソ）を押さえて鳴らす人もいて、その場合はいちばん低い音がソになります。
1弦の音が鳴りません。
1弦は開放の E（ミ）を鳴らします。2弦1フレットを押さえる人差し指が1弦に触れていると、1弦の音が止まります。人差し指を立てて、指先で2弦だけを押さえているかを確かめます。
