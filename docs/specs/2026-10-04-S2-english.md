# 英語版 /fretboard/en/・hreflang・内部リンク・構造化データ（段階2）

## 目的
`https://guitartoolbox.site/fretboard/en/` で、指板トレーナーのすべての画面が英語で動く状態にする。
日本語版 `/fretboard/` と hreflang で結び、同じ言語のハブへリンクし、構造化データを持たせる。
言語・内部リンクの決まりは guitartoolbox の ADR-0001、このアプリ固有の決定（PWA と manifest）は ADR-0004 が正。
英語圏の需要（guitar fretboard 18,100/月、guitar fretboard notes 8,100/月）を取りに行くのが目的なので、英語は直訳ではなく、英語圏のギター教材で普通に使う言い方にする。

## 着手条件
- 段階1（`docs/specs/2026-10-04-S1-workers-subpath.md`）が実装済みで、`https://guitartoolbox.site/fretboard/` に公開されている

## やること
1. 言語の仕組みを入れる。依存ライブラリは足さず、`src/i18n/`（置き場所は実装で決めてよい）に日本語と英語の辞書と、URL のパスから言語を決める関数を置く。パスが `/fretboard/en/` で始まれば英語、それ以外は日本語。保存した設定やブラウザの言語では決めない。
2. 画面に出る文言をすべて辞書へ移し、英語を用意する。対象は、5タブの画面、練習・統計・設定、学習マップとレッスン本文（21件）、エラー画面、確認ダイアログ、`aria-label`・`title` 属性、インストールの案内、書き出し・読み込みのメッセージ。
   - 音名は英語の表記（C、C#、Db など）、度数は英語圏の一般的な呼び方（minor 3rd、perfect 5th など）にそろえる。用語の対応表を辞書の近くに置き、同じ概念を画面ごとに別の英語で呼ばない。
3. Vite の複数ページ構成で `dist/fretboard/index.html`（日本語）と `dist/fretboard/en/index.html`（英語）を出す。JS と CSS は共通でよい。英語版の `<html lang="en">`、title、meta description、og:title・og:description・og:locale（`en_US`）を英語にする。
4. 両方の HTML に、自己参照の canonical、hreflang（`ja` → `/fretboard/`、`en` → `/fretboard/en/`、`x-default` → `/fretboard/en/`）を絶対 URL で入れる。
5. 画面のヘッダーかフッターに、同じ言語のハブへのリンク（日本語は `https://guitartoolbox.site/`、英語は `https://guitartoolbox.site/en/`）と、もう一方の言語版へのリンク（表示は「English」「日本語」）を置く。この2つのリンクは `index.html` 側にも静的に書き、JavaScript の実行前から HTML にあるようにする。
6. JSON-LD の `WebApplication`（name、url、description、inLanguage、applicationCategory、operatingSystem は `Any`、offers の price は `0`）を両言語の HTML に置く。
7. PWA: 英語版用の manifest（name・short_name・description は英語、`start_url` と `id` は `/fretboard/en/`、`scope` は `/fretboard/`）を出し、英語版の HTML から参照する。Service Worker は `/fretboard/sw.js` の1つのまま両言語を受け持ち、英語版の HTML もプリキャッシュとオフライン表示の対象にする。
8. `/fretboard/sitemap.xml` に `/fretboard/` と `/fretboard/en/` の2件を載せ、それぞれに `xhtml:link`（ja・en・x-default）を付ける。
9. 再読込・設定のリセット・エラー画面からの復帰で、今の言語の URL に戻るようにする（英語版から日本語版へ落ちないこと）。
10. 保存データ・書き出しの形式は変えない。日本語版で書き出した JSON を英語版で読み込めること。

## やらないこと
- ブラウザの言語による自動転送・自動切り替え（ADR-0001 で不採用）
- 機能ごとの URL（段階3）
- 保存キー・保存形式の変更、練習ロジック・画面デザインの変更
- 他のツールへの直接リンク（ハブ経由で足りる。ADR-0001）

## 変更してよいファイル
- vite.config.ts、index.html、英語版の HTML（新規）、package.json（scripts のみ）
- 画面の文言を持つ src/ 配下のファイル、辞書と言語判定の新規ファイル
- sitemap を出すスクリプト、manifest の設定
- AGENTS.md の該当箇所、context/STATUS.md、テスト

## 受け入れ条件
- `npm run build`・`npm test`・`npm run lint` が通る。`npx wrangler deploy --dry-run` が通る
- dist に `fretboard/index.html`・`fretboard/en/index.html`・英語版の manifest・`fretboard/sitemap.xml` がある
- `npx wrangler dev` で次が成り立つ（Playwright CLI で実測）
  - `/fretboard/en/` が 200 で開き、5タブ・練習1回・統計・設定・レッスン1件を開いたとき、`document.body.innerText` にひらがな・カタカナ・漢字が1文字も無い（`/[\u3040-\u30ff\u4e00-\u9fff]/` に一致しない）
  - `/fretboard/` は従来どおり日本語
  - 言語の切り替えリンクで相互に移れる。ハブへのリンクが同じ言語のハブを指す
  - 英語版で設定のリセットをすると `/fretboard/en/` に戻る
  - 日本語版で書き出した JSON を英語版で読み込むと成績が戻る
- 両方の HTML に canonical・3つの hreflang・JSON-LD（`JSON.parse` できる）があり、ハブと言語切り替えのリンクが JavaScript 無効でも HTML に存在する
- 辞書の日本語と英語でキーの集合が一致する（テストで確認）
- `fretboard/sitemap.xml` が2件を載せ、それぞれに3つの `xhtml:link` がある

## 公開後に運営者がやること
- 英語版でインストールした PWA が `/fretboard/en/` で開き、オフラインでも開けることを確かめる
- GSC の「URL 検査」で `/fretboard/en/` を1回検査する
- 英語の文言を一度通しで読み、ギター用語の違和感がないかを確かめる（必要なら codex-consult か英語話者に見てもらう）
