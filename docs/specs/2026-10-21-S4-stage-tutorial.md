# 学習マップを「覚え方 → 見ながら3問 → 見ずに10問」の11段階にする

## 目的

指板の音名と度数を「覚えている前提」で出題している状態をやめ、法則を1つずつ教えてから練習させる。
2026-10-21 に運営者が実際に使って「覚えられない」「突き放されている感じがする」と感じた。調べると、次のとおりだった。

- 学習マップ（`src/data/phases.ts` の5段階）と、ホームの目標カードの「音名の練習をはじめる」は、説明なしで出題を始める。
- 誤答のときは正解の音名しか出さない（`src/App.tsx` の `getFeedbackMsg`）。
- 覚え方は「ヒントを見る」の1行と、理論のレッスン（`src/data/lessons.ts` の notes・octave・degree）にしか無い。
- 度数の練習はルートを音名で選ぶだけで、ルートの位置が指板に出ない。そのため形で覚えられない。

そこで、学習マップの各段階を次の3ステップにする。

1. **覚え方**: 法則を1つだけ、短い文と指板の図で見せる。
2. **見ながら3問**: 法則の目印を指板に薄く出したまま3問答える。
3. **見ずに10問**: 目印を消して10問答える。誤答のときは、正解に加えて「法則の名前と、知っている音からの道筋」を出す。

段階は音名6つと度数5つの、計11段階にする。

## 着手条件

- `src/App.tsx` の `getHintText` のヒント修正（コミット 97e131a）が入っていること。法則の文言をそろえるため

## 段階の定義

弦の index は既存どおり 0 = 6弦（E2）… 5 = 1弦（E4）。「細い隣の弦」は index + 1。
3弦（index 3）と2弦（index 4）の間だけ、隣り合う弦の音程が長3度（4半音）で、ほかは完全4度（5半音）。法則の例外はすべてこの1か所から来る。

### 音名の6段階（出題は既存の `position-to-note`）

| id | 名前 | 出題の範囲 | 法則（覚え方に出す内容） | 覚え方の図で光らせる場所 | 目標の反応時間 |
|---|---|---|---|---|---|
| `open-strings` | 開放弦 | 全弦・0F・全音 | 6弦から順に E A D G B E。太い弦から読む | 全弦の 0F | 2000ms |
| `string6-naturals` | 6弦のナチュラル音 | 6弦・0〜12F・ナチュラル | E-F と B-C の間だけ1フレット、ほかの隣り合う音は2フレット。開放 E から数える | 6弦の 0・1・3・5・7・8・10・12F | 2500ms |
| `string5-naturals` | 5弦のナチュラル音 | 5弦・0〜12F・ナチュラル | 同じ数え方を開放 A から | 5弦の 0・2・3・5・7・8・10・12F | 2500ms |
| `fret5-bridge` | 5フレット＝細い隣の弦の開放 | 全弦・0〜5F・ナチュラル | 5フレットの音は、細い隣の弦の開放と同じ。3弦だけは4フレットが2弦の開放 B | 6・5・4・2弦の 5F と 3弦の 4F、その行き先の開放弦 | 2500ms |
| `octave-shape` | オクターブの形 | 全弦・0〜12F・ナチュラル | 同じ音は「2本細い弦の2フレット先」。3弦と2弦の間をまたぐと「3フレット先」 | 例: 6弦3F（G）→ 4弦5F → 2弦8F、5弦3F（C）→ 3弦5F → 1弦8F | 2200ms |
| `sharps-flats` | シャープとフラット | 全弦・0〜12F・全音 | ナチュラル音の1フレット右が ♯、1フレット左が ♭。同じ場所に2つの名前がある | 6弦の F・F♯/G♭・G | 2500ms |

### 度数の5段階（新しい出題: ルートの位置を指板に出し、目標の位置の度数を答える）

ルートは6弦か5弦に置く。答えは既存の `IntervalSelector`（R・m2…M7 の12択）で選び、オクターブ上のルートは `R` を正解とする。

| id | 名前 | 出題する度数 | 目標を置く弦（ルートの弦からいくつ細いか） | 法則 | 目標の反応時間 |
|---|---|---|---|---|---|
| `deg-power` | 5度とオクターブ | R（オクターブ）・P5 | 0〜2本 | 5度は細い隣の弦の2フレット先。オクターブは2本細い弦の2フレット先（パワーコードの形） | 2500ms |
| `deg-fourth` | 4度 | 上に P4 を足す | 0〜2本 | 4度は細い隣の弦の同じフレット | 2500ms |
| `deg-thirds` | 長3度・短3度 | 上に M3・m3 を足す | 0〜2本 | 長3度は細い隣の弦の1フレット手前、短3度は2フレット手前 | 2500ms |
| `deg-rest` | 7度・2度・6度 | 12個すべて | 0〜2本 | 短7度は2本細い弦の同じフレット、長7度は1フレット先、長6度は1フレット手前。長2度は同じ弦の2フレット先 | 3000ms |
| `deg-cross` | 2弦をまたぐ形 | 12個すべて | 2弦か1弦だけ（ルートが6弦なら4〜5本、5弦なら3〜4本細い弦） | 3弦と2弦の間をまたぐと、同じ形が1フレット右にずれる | 3000ms |

度数の出題の作り方:

- ルートの弦を 6弦か5弦から選び、ルートのフレットは、目標の窓（ルートのフレットの3つ手前から4つ先）が 0〜12F に収まる範囲から選ぶ。
- 窓の中で、許された弦にあり、ルートの位置そのものではなく、度数が段階の集合に入る位置から1つ選ぶ。度数は段階の集合から先に選び、その度数を作る位置を探す。見つからなければ選び直す。
- `deg-power`〜`deg-rest` の目標は、3弦と2弦の間をまたがない（ルートが6弦なら4弦まで、5弦なら3弦まで）。`deg-cross` の目標は必ず2弦か1弦に置く。
- 度数は半音の差（12で割った余り）で決め、形の表から逆算しない。表は法則の説明にだけ使う。

## やること

### 1. 段階のデータと純粋な関数

1. `src/data/phases.ts` の `PHASES` を、上の11段階に置き換える。音名と度数のどちらの段階か、覚え方の文、図で光らせる場所、目標の正答率と反応時間を1か所に持たせる。数値は弾きながら見直す前提なので、コード中に散らさない。
2. 誤答のときに出す「道筋」を返す関数を、画面から切り離して作る（例: `explainAnswer(stageId, position, rootPosition, accidental)`）。返す文の例:
   - `string6-naturals` の6弦7F: 「開放 E から: E(0) F(1) G(3) A(5) B(7)」
   - `fret5-bridge` の4弦5F: 「5フレット = 細い隣の弦(3弦)の開放音(G)」。5F でない場所は、その弦の開放から数える道筋
   - `octave-shape` の4弦5F: 「6弦3F の G から、2本細い弦の2フレット先」。太い側に2本の弦が無いときは、開放か12Fから数える道筋
   - `sharps-flats`: 「G(3F) の1フレット左 = G♭」。`accidental` の設定（♯表記か♭表記か）に合わせる
   - 度数: 「4度 = 細い隣の弦の同じフレット」。`deg-cross` では「2弦をまたいだので1フレット右」を添える
3. 度数の出題を作る関数を、乱数の生成器を引数で受け取る純粋な関数にする。同じ種から同じ出題が出るようにする。
4. 段階の進み具合を保存する。キーは `gft-` で始める（`src/data/backup.ts` は `gft-` のキーを丸ごと書き出すので、書き出し・読み込みに自動で入る）。保存するのは段階ごとに「覚え方を見た日時」「見ずに10問の最高の正答数と、そのときの平均反応時間」「クリアした日時」。
5. クリアの条件は「見ずに10問で9問以上正解し、平均反応時間が段階の目標以下」。
6. 既に練習の記録がある利用者を最初からやり直させない。音名の段階は、いまの `computePhaseStatus` と同じ判定（1マス3回以上・目標の正答率と反応時間・範囲の9割）を満たしていれば、クリア扱いにする。

### 2. 画面

1. 学習マップ（`src/components/PhaseMap.tsx`）に11段階を、音名と度数の2つの見出しに分けて並べる。各行に状態（未着手・覚え方を見た・クリア）を出し、最初の未クリアの段階に「次はここ」を出す。
2. **ロックはしない**。ADR-0002（ソフトガイド）のとおり、どの段階もいつでも始められる。順番は「次はここ」の表示とホームの導線で示す。
3. 段階を選ぶと、ステップ1（覚え方）から始まる。クリア済みの段階では、ステップ1を飛ばして見ずに10問から始める選択肢も出す。
4. ステップ1（覚え方）: 筐体の中に指板の窓を置き、光らせる場所に音名（度数の段階はルートに「R」と度数）を出す。法則の文は窓の外、筐体の中に2〜3行で置く。主ボタンは「見ながら3問」。関連するレッスン（notes・octave・degree）があれば、文字リンクで開けるようにする。
5. ステップ2（見ながら3問）: 既存の練習の筐体（読み取り・指板の窓・フットスイッチ）を使い、覚え方で光らせた場所の音名を指板に薄く出したまま3問出す。度数の段階では、ルートの位置に「R」を常に出す。3問終えたら、ステップ3の開始ボタンを出す。
6. ステップ3（見ずに10問）: 目印を消して10問出す。度数の段階のルートの「R」だけは出し続ける。誤答のときは、いまの「不正解... 正解: X」の下に、法則の名前と道筋を1行で出す。誤答のときの待ち時間（`WRONG_DELAY` = 2800ms）は変えない。
7. 10問の結果画面に、正答数・平均反応時間・クリアしたかを出す。クリアしたら主ボタンを「次の段階へ」、しなかったら「覚え方をもう一度」と「もう一度10問」にする。
8. ホームの目標カードで、目標が「指板の音名を覚えたい」のときの「音名の練習をはじめる」は、最初の未クリアの音名の段階のステップ1を開くようにする。ほかの目標の導線は変えない。
9. 指板に「R」と薄い音名を出すために `Fretboard` に任意の props を足してよい（例: ルートの位置、薄く出すラベル）。既存の呼び出し側の表示は変えない。
10. 見た目は `docs/design-system/README.md` に従う。とくに次を守る。
    - 筐体は1画面に1〜2個。窓には文章の段落を入れない
    - 主ボタンは1画面に1つ。琥珀は読み取りの主な数字・主ボタン・選択中だけ
    - 文字サイズは表の値だけ（`text-lg`・`text-2xl`・`text-4xl` 以上は使わない）。色はトークン名で指定する
    - カードの格子を作らない。段階の一覧は罫線で区切ったリストの行にする

### 3. 英語版

- 日本語の表示文字列を足したら、`src/i18n/ui.ts` に英語のキーを足す（`src/i18n/english.test.ts` が辞書の抜けを落とす）。テンプレート文字列は既存と同じ `{0}{1}` 形式のキーにする。
- 英語は直訳ではなく、英語圏のギター教材で普通に使う言い方にする（例: 「細い隣の弦」は "the next thinner string"、「2本細い弦の2フレット先」は "two strings over, two frets up"）。

## 受け入れ条件

- `npm run build`・`npm test`・`npm run lint` が通る。lint の警告を増やさない（2026-10-21 時点で11件、すべて既存）
- 単体テストで次を確かめる
  - 段階は11個で、id が重ならず、音名6・度数5の順に並ぶ
  - 音名の各段階の出題範囲の全マスで、道筋の文が空でなく、文の最後の音名が `getNoteAt` の答えと一致する（`accidental` の ♯・♭ 両方）
  - `fret5-bridge` の5Fの道筋は細い隣の弦（index + 1）を指し、3弦（index 3）は4Fが2弦の開放 B を指す
  - `octave-shape` の道筋の元の場所と答えの場所が、実際に同じ音名になる
  - 度数の出題は、同じ種から同じものが出る。1,000問生成して、すべて次を満たす: ルートは6弦か5弦、目標はルートの位置と違う、目標は窓の中で 0〜12F、度数は段階の集合に入る、`deg-power`〜`deg-rest` は2弦・1弦に目標を置かない、`deg-cross` は必ず2弦か1弦に置く
  - 度数の道筋の度数が、半音の差から求めた度数と一致する
  - クリアの条件（9/10 以上かつ平均が目標以下）と、記録がある利用者の音名の段階がクリア扱いになること
  - 段階の進み具合の保存が無い古いバックアップを読み込んでも、エラーにならずに既存の成績が残る
- `npm run dev`（`/fretboard/`）で Playwright CLI を使って次を実測する
  - 学習マップに音名6・度数5の段階が出て、何も記録が無い状態では `open-strings` に「次はここ」が出る
  - `open-strings` を選ぶと覚え方が出て、指板の 0F の6か所に E A D G B E が出る
  - 「見ながら3問」では指板に目印が出ており、3問のあとの「見ずに10問」では目印が消える
  - 見ずに10問でわざと1問まちがえると、正解と道筋が出る
  - 10問で9問以上正解すると結果画面にクリアが出て、学習マップの「次はここ」が `string6-naturals` に移る
  - 度数の段階 `deg-fourth` で、指板にルートの「R」が出て、答えを選ぶと正誤が出る
  - ホームで目標「指板の音名を覚えたい」の「音名の練習をはじめる」を押すと、最初の未クリアの音名の段階の覚え方が開く
  - 幅 390px で、ページに横スクロールが出ない（指板の窓の中の横スクロールはよい）
  - 英語版（`/fretboard/en/`）で段階1を覚え方から見ずに10問の結果まで進めたとき、どの時点でも `document.body.innerText` にひらがな・カタカナ・漢字が1文字も無い
  - 既存の練習（基本の3モード、チャレンジ、今日の練習）が従来どおり動く
- 390px と 1440px で、覚え方・見ながら3問・結果画面のスクリーンショットを撮り、デザインシステムの「部品のルール」に反するところが無いことを自分で確かめる

## 公開後に運営者がやること

- 実機で段階1〜4と度数の段階1〜2を一通り進め、法則の文が分かりやすいか、目標の反応時間が厳しすぎないかを確かめる。数値は `src/data/phases.ts` の1か所で直す
