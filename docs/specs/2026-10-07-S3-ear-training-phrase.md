# 耳トレの固有 URL /fretboard/ear-training/ とフレーズ再現モード

## 目的
聴いた短いフレーズを指板で再現する練習（フレーズ再現モード）を、既存の耳トレに足す。
あわせて耳トレを `/fretboard/ear-training/`（日本語）と `/fretboard/en/ear-training/`（英語）の固有 URL で開けるようにし、検索から直接着地できるようにする。
狙うのは「耳で聴く」「指板で探す」「度数で理解する」を1問でつなぐ体験で、想定する利用者は「TAB は弾けるが、聴いた音を自分で探せない人」。

需要の根拠（2026-10-07 実測、affiliate-brain `context/FINDINGS.md` §84 追記）: 日本は「耳コピ やり方」1,300/月・「ギター 耳コピ」320/月で、上位は解説記事だけでツールが無い。米国は「ear training」3,600/月・「interval ear training」1,000/月・「guitar ear training」390/月。
機能ごとの URL は段階3の予定だったが、この1画面だけ先に持たせる。ほかの画面の URL 化はこの指示書の範囲外。

## 着手条件
- 段階2（`docs/specs/2026-10-04-S2-english.md`）が実装済みで、辞書と URL からの言語判定がある

## やること

### 1. フレーズ再現モード
1. 耳トレの出題モードに「フレーズ」を足す。既存の3度・コード・音程のモードは変えない。
2. 1問の流れ:
   1. キーを示す。主和音を `playChord` で鳴らし、続けて主音を1つ鳴らす。
   2. フレーズを `playMidi` で1音ずつ等間隔に鳴らす。リズムは固定。
   3. 利用者は指板をタップして、聴いた順に音を入れる。タップした音はその場で鳴らす。
   4. 音数ぶん入れたら判定する。結果として、正解の音名（例: E–G–A–G）と、キーに対する度数（例: 3–5–6–5）を並べて出す。正解のフレーズと自分の回答を、それぞれ聴き直せるようにする。
   5. 正解したら「同じ度数で別のキーへ」を選べる。選ぶと、同じ度数の並びを別のキーで出題する。
3. 正誤の判定:
   - 同じ高さの音なら、弦とフレットの位置が違っても正解とする。
   - 「オクターブ違いも正解」の設定を持つ。レベル1・2では既定でオン、レベル3以上では既定でオフにする。
4. ヒントは3段階で、押すたびに次を出す。
   1. 音の動き（上がった・下がった・同じ）を矢印で示す。
   2. キーの音階の音を、練習範囲の中で指板に薄く示す。
   3. 次の1音を示す。
   ヒントを使った問題は、正解でも成績上は区別して記録する。
5. レベルは次の4段階とする。数値は弾きながら見直す前提なので、コード中に散らさず1か所にまとめる。

   | レベル | 音数 | 音の動き | 最初の音 | キー |
   |---|---|---|---|---|
   | 1 | 2〜3 | 隣の音階音への順次進行のみ | 示す | C メジャー |
   | 2 | 3 | 3度までの跳躍を含む | 示す | C・G・F メジャー |
   | 3 | 4 | 5度までの跳躍を含む | 示さない | 全12キーのメジャー |
   | 4 | 4〜5 | オクターブまでの跳躍を含む | 示さない | 全12キーのメジャーとナチュラルマイナー |

6. フレーズは、既存の練習範囲（弦とフレット）の中で弾ける音だけから作る。範囲内でレベルの条件を満たせない場合は、出題せずに範囲を広げる案内を出す。
7. フレーズの生成と判定は、画面から切り離した純粋な関数にする。乱数の生成器を引数で渡せるようにし、同じ種から同じフレーズが出るようにする。
8. キー操作を入れる。Space で問題を再生、Backspace で最後の1音を取り消し、Enter で判定または次の問題へ進む。文字入力中は発火させない。再生ボタンは大きく置き、何回聴いてもよい。聴いた回数は成績と一緒に記録する。
9. 成績は既存の耳トレと同じ記録の仕組み（`recordSkill` とセッション）に、フレーズ用の新しい項目として足す。既存の保存キーと形式は変えず、項目を追加するだけにする。項目が無い古い保存データもそのまま読める。書き出し・読み込みに新しい項目も含める。

### 2. 固有 URL
1. Vite の複数ページ構成に、`dist/fretboard/ear-training/index.html`（日本語）と `dist/fretboard/en/ear-training/index.html`（英語）を足す。JS と CSS は共通でよい。
2. URL のパスが `ear-training/` で終わる場合、アプリは最初から練習画面の耳トレを開く。言語はパスで決める段階2の仕組みをそのまま使う。
3. アプリの中で耳トレに切り替えたときは `history.replaceState` で URL を耳トレの URL に変える。ほかの画面へ移るときは、その言語のトップの URL（`/fretboard/` または `/fretboard/en/`）に戻す。
4. 2つの HTML に、それぞれ専用の title、meta description、og:title・og:description、自己参照の canonical、hreflang（`ja`、`en`、`x-default` は英語）、JSON-LD の `WebApplication` を入れる。
   - 日本語の title の例: 「耳コピ練習｜聴いたフレーズを指板で弾く耳トレ — Guitar Toolbox」
   - 英語の title の例: 「Guitar Ear Training — Play Back Melodies on the Fretboard」
5. 2つの HTML には、JavaScript を実行しなくても読める説明文を静的に置く。中身は、見出し1つと、耳コピ練習の進め方を述べた300〜500字程度の本文（英語は同程度の語数）。英語は直訳ではなく、英語圏のギター教材で普通に使う言い方にする。アプリの描画でこの説明文を消さない。
6. Service Worker のプリキャッシュとオフライン表示の対象に、2つの HTML を足す。
7. `/fretboard/sitemap.xml` に2件を足し、それぞれに `xhtml:link`（ja・en・x-default）を付ける。

## やらないこと
- マイクで弾いた音を判定する機能
- リズムが変わるフレーズ、伴奏の上でのフレーズ
- コード進行の聴き取り（需要が小さいため見送り。2026-10-07）
- ほかの画面の固有 URL（段階3）
- 音色の変更（三角波のまま）
- ハブ（guitartoolbox）の変更。ハブのカードへのリンク追加は guitartoolbox 側で別に行う

## 変更してよいファイル
- `src/components/EarTrainingQuiz.tsx`、フレーズ再現モードの新規コンポーネント、フレーズの生成と判定の新規ファイル
- `src/App.tsx`（最初の画面の決定と URL の切り替えだけ）
- `src/data/skillStore.ts`・`src/data/backup.ts`（項目の追加だけ）
- 辞書（段階2で作るもの）
- `vite.config.ts`、新規の HTML 2つ、sitemap を出すスクリプト、Service Worker の設定
- テスト、`README.md` の機能一覧、`AGENTS.md` の該当箇所、`context/STATUS.md`

## 受け入れ条件
- `npm run build`・`npm test`・`npm run lint` が通る。`npx wrangler deploy --dry-run` が通る
- 単体テストで次を確かめる
  - 同じ種からは同じフレーズが出る。各レベルの音数・跳躍の幅・キーの条件を守る
  - 生成した音はすべて、指定した練習範囲の中で弾ける
  - 同じ高さの音なら別の位置でも正解になる。オクターブ違いは、設定がオンのときだけ正解になる
  - 度数の表示がキーに対して正しい（例: C メジャーで E–G–A–G は 3–5–6–5）
  - 「同じ度数で別のキー」で、出題の度数の並びが変わらない
  - フレーズの成績が無い古い保存データを読み込んでも、エラーにならずに既存の成績が残る
- `npx wrangler dev` で次が成り立つ（Playwright CLI で実測）
  - `/fretboard/ear-training/` と `/fretboard/en/ear-training/` が 200 で開き、最初から耳トレが表示される
  - 英語版の耳トレで、フレーズを1問解いて答え合わせまで進めたとき、`document.body.innerText` にひらがな・カタカナ・漢字が1文字も無い
  - 既存の耳トレ（3度・コード・音程）が従来どおり動く
  - アプリ内で耳トレへ移ると URL が耳トレの URL になり、ほかの画面へ移るとトップの URL に戻る
  - 日本語版で書き出した JSON を英語版で読み込むと、フレーズの成績も戻る
- 2つの HTML に、canonical・3つの hreflang・JSON-LD（`JSON.parse` できる）・静的な説明文が、JavaScript 無効でも存在する
- `fretboard/sitemap.xml` が4件を載せ、それぞれに3つの `xhtml:link` がある

## 公開後に運営者がやること
- 実機で、レベル1〜2を数問ずつ弾き、音数・跳躍・ヒントの段階が練習として適切かを確かめる。数値は1か所にまとめてあるので、そこで調整する
- GSC の「URL 検査」で2つの URL を1回ずつ検査する
- guitartoolbox の tools.json で、指板トレーナーのカードから耳トレへのリンクを足すかを決める
