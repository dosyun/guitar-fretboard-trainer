# Guitar Fretboard Trainer デザインシステム（機材の操作盤）

2026-10-15 制定。見た目の正本はこの文書と `src/index.css` の `:root`（トークン、つまり色・文字・余白の共通値）、指板SVGの色は `src/data/boardPalette.ts` である。ページごとに色や角丸を新しく作らず、ここにある値だけを使う。
[ADR-0003](../adr/0003-dark-studio-keep-antd.md)（ダーク・スタジオ系、Ant Design をトークンで上書き）の判断は引き継ぎ、この文書はその「構成と部品」を具体化する。

## 設計の前提

| 項目 | 内容 |
|---|---|
| 利用者と利用場面 | 独学のギター初〜中級者。ギターを抱えたまま、譜面台か机に置いたスマホ・PCに目を落とし、片手でタップする。1回10〜15分、夜の練習も多い（仮定: 夜間利用はアクセス解析で未確認） |
| 最優先の行動 | 今日の練習を始め、指板の問題に反射で答える |
| 判断・操作に必要な情報 | 出題位置（何弦何フレット）、回答の12音、いまの反応時間、残り問題数、正誤 |
| 最初の画面に置くもの／置かないもの | 置く: 指板・回答ボタン・反応時間。置かない: 宣伝コピー、英字の飾りラベル、モード選択の全展開（折りたたむ） |
| 主役にする情報 | 指板そのものと、1問ごとの反応時間（ミリ秒）。このアプリにしかない実データ |
| 代表画面 | 練習（基本・位置→音名）の出題〜回答直後 |
| 独自性を出す場所／普通にする場所 | 出す: 読み取り表示（音名・反応時間メーター）、指板の窓、12音のフットスイッチ。普通にする: ナビゲーション、設定フォーム、レッスン本文、リンク |

入れ替えテストの改修前の結果: 練習画面は指板があるため成立しないが、ホームは「大見出し＋短文3行＋角丸カードの格子」で、指板の小さな飾り図を除けば語学アプリや筋トレアプリでも成立した。全ページが「小ラベル → 見出し → リード → カード」の同じリズムで続き、英字ラベル（PRACTICE など）と装飾の琥珀の四角・点が載っていた。

## 構成の3案

| 案 | 出発点の実物 | 主役 | 代表画面の並び順 | 合う理由 | 弱点 |
|---|---|---|---|---|---|
| A | チューナーとエフェクターの筐体 | 巨大な音名と反応時間メーター | 読み取り表示 → 指板の窓 → 12音のフットスイッチ | 抱えたまま目を落とす使い方と夜の練習に合う。ADR-0003 を引き継げる | 配色が今と近く、変化は構成の差が中心 |
| B | 単色の面に弦を引いたポスター | 橙の色面と指板（スマホは縦置き） | 問題と反応時間 → 指板 → 紺の帯に12音 | 一目で独自。縦置きでフレットが大きい | 全クイズの指板描画の作り直しが要る。成績・理論へ展開しにくい |
| C | 1950〜60年代のカタログと教則本 | 木目の指板の図版と番号付き注記 | 見出し → 図1 → 注記 → 記録表と回答票 | 理論と「なぜ」の表示に合う | 明るい紙面が夜にまぶしい。読ませる構成で反射の練習と逆向き |

比較したボードは `pinterest-directions.jpg`、ラフは [directions/](directions/)（`a.html`〜`c.html`）にある。比較シートの画像 `directions.png` と参考ボードはピン画像を含むため、公開リポジトリにはコミットしない（`.gitignore` 済み）。
採用したのは A。理由: 最優先の行動（反射で答える）を一番速くし、既存の暗い画面の判断と矛盾しない。B の「指板を画面の主役にする」判断は、A の指板の窓を広く取ることで部分的に取り入れる。

## 方針

カードの格子、英字の飾りラベル、装飾の点と四角、短文を重ねたキャッチコピーをやめる。代わりに、指板と反応時間を「1台の機材」の表示と操作部として見せる。

| 使う（根拠にした判断・計測値） | 使わない |
|---|---|
| 1画面の主操作を1つの「筐体」に収める（主参考: 1台＝1つの面） | 情報ごとに角丸カードを並べる格子 |
| 読み取りの「窓」（筐体より暗い面）に数字と指板を入れる（主参考: 表示窓） | 文章をカードや窓で囲む |
| 巨大な音名と反応時間メーター（補助参考: 音名1文字・目盛りと針） | 中間サイズの見出しを並べて強弱をなくすこと |
| 12音をフットスイッチの形に並べ、押した結果を下の状態ランプで示す（主参考: 踏みスイッチと緑のランプ） | `shadow-*` で浮かせたボタン |
| 状態ランプ（小さな丸）は正誤・クリアなど意味がある時だけ | 意味のない琥珀の点・四角、見出し横の飾り |
| ラベルは日本語の短い名詞 | PRACTICE・LESSON などの英字の飾りラベル |
| 見出しは「その下に何があるか」を名指しする | 「〜、〜。」の体言止め、短文の重ね、「〜しよう」の呼びかけ |

## 構成

### 練習（代表画面）

元の骨格は「英字ラベル＋見出し → 練習メニューのカード → 出題モードのカード → スコア4マス → 問題文 → 指板のカード → 回答ボタン → 範囲のカード」で、指板が画面の下半分に押し出されていた。

| 順 | セクション | 組み方 | 画面に占める比重 |
|---|---|---|---|
| 1 | 設定の1行 | 練習メニュー・出題モード・範囲を、閉じた1行ずつの `details` にする。開始後は閉じる | 1割以下 |
| 2 | 筐体: 読み取り | 左の窓に巨大な音名（回答前は「?」）、問題文、反応時間メーター。右に小さな読み取り4つ（今回の反応・平均・正答・進み） | 2.5割 |
| 3 | 筐体: 指板の窓 | 指板を窓いっぱいに | 3.5割 |
| 4 | 筐体: 12音のフットスイッチ | 6列×2段（スマホ 4列×3段）、下に状態ランプ | 3割 |
| 5 | 終了 | 筐体の下に控えめなボタン | — |

開始前は、2 の読み取りの位置に窓（`bg-glass`）を置き、問題数の切り替えと開始ボタン（主ボタン）を入れる。コードトーン・進行・トライアド・キー機能・耳トレ・ガイド音も同じで、共通部品 `QuizStart`（`QuizChrome.tsx`）を筐体の中に置く。終了ボタン（`QuizFooter`）と1行の説明は筐体の下に置く。

### ホーム

元の骨格は「小ラベル＋大見出し＋短文3行 → 今日の練習カード（飾りの指板図）＋目標カード＋レッスンカード → 学習マップ＋手応え」。

| 順 | セクション | 組み方 | 画面に占める比重 |
|---|---|---|---|
| 1 | 筐体: 今日の練習 | 左の窓に指板習熟度（%）を巨大な数字で、横に連続日数・平均反応・回答数。右に問題数の切り替えと開始ボタン（主ボタン） | 4割 |
| 2 | 次にやること | 弱点の場所・目標・次のレッスンを、カードではなく罫線で区切った3行のリストにする | 2.5割 |
| 3 | 学習マップ | フェーズ一覧（既存の PhaseMap） | 残り |

## トークン

### 色

コントラスト比は WCAG の相対輝度の式で計算した（`contrast.py`）。本文に使う色はすべて 4.5:1 以上。

| トークン | 値 | 用途 | コントラスト |
|---|---|---|---|
| `--bg` | `#121315` | ページ背景（機材を置く部屋） | — |
| `--surface` | `#1f2124` | 筐体の面、パネル | — |
| `--panel` | `#2a2d31` | 筐体の上の部品（スイッチ、入力欄、選択肢） | — |
| `--glass` | `#0a0b0c` | 読み取りの窓、指板の窓 | — |
| `--hair` | `#34373c` | 境界線 | 装飾のみ |
| `--case-edge` | `#3d4147` | 筐体の上辺の明るい縁（影の代わりに厚みを出す） | 装飾のみ |
| `--ink` | `#ebe7df` | 見出し、本文、スイッチの文字 | surface 上 13.1、panel 上 11.2 |
| `--dim` | `#979aa0` | 補足文、ラベル | surface 上 5.7、bg 上 6.6、panel 上 4.9 |
| `--accent` | `#ffb02e` | 読み取りLEDの数字、主ボタン、選択中 | glass 上 10.8、surface 上 8.8。主ボタンの文字 `--bg` は 10.2 |
| `--accent-soft` | `#3a2e17` | 選択中の背景 | — |

| `--wrong` | `#ef6a4f` | 不正解の状態ランプ・文字 | surface 上 5.3 |

琥珀は1画面につき「読み取りの主な数字」と「主ボタン1つ」と「選択中の表示」に限る。見出し・ラベル・飾りには使わない。
旧トークン名（bg・surface・panel・hair・ink・dim・accent・accent-soft・correct・wrong）は名前をそのまま残し、値だけ差し替えた。`glass` と `case-edge` を追加した。

指板SVG（`boardPalette.ts`）は木の指板を残す。指板は実物の素材であり、灰の筐体の中で唯一の暖色の面として主役を際立たせるため。

### 書体

- 日本語と本文は system-ui（Hiragino・Noto Sans JP・Meiryo）
- 数字・音名・度数・回答時間だけ DM Mono（`font-mono`、`tnum`）。英字ラベルの飾りには使わない
- 太さは 400 と 600 の2段（巨大な読み取りだけ DM Mono 500）

### 文字サイズ

| Tailwind | 値 | 主な用途 |
|---|---|---|
| `text-xs` | 12px | ラベル、単位、補足 |
| `text-sm` | 14px | 補足文、ボタン、リスト |
| `text-base` | 16px | 本文、問題文 |
| `text-xl` | 20px | 画面の見出し（h1）、スイッチの音名 |
| `text-3xl` | 30px | 小さな読み取りの数字 |
| `text-7xl` | 72px | 巨大な読み取り（スマホ） |
| `text-8xl` | 96px | 巨大な読み取り（PC） |

`text-lg`・`text-2xl`・`text-4xl` 以上の中間サイズは新しく使わない（計測: 中間の大きさを使わない）。px の直書き（`text-[13px]` など）はしない。

### 余白

Tailwind の 1・2・3・4・6・8（4・8・12・16・24・32px）だけを使う。筐体の内側は `p-3 sm:p-6`、筐体の中の部品間は `gap-3 sm:gap-4`、ページのセクション間は `gap-6 sm:gap-8`。

### 角丸と影

| 対象 | 値 | 理由 |
|---|---|---|
| 筐体 | `rounded-2xl`（16px） | 機材のケースの角 |
| 窓・スイッチ・ボタン・入力欄 | `rounded-lg`（8px） | 部品の角 |
| タグ（銘板） | `rounded`（4px） | 印字された小さな板 |
| 状態ランプ・音の印 | `rounded-full` | LED と、指板のマーカーと同じ丸（凡例・ボイシング一覧の音の印） |
| 計測バー・進捗バー | 角丸なし | 機材の目盛り |
| antd の上書き | `Segmented` 外枠 8px・項目 6px（外枠 − 内側余白 3px）、`Tabs` の下線 0 | 入れ子の角をそろえるため。`src/index.css` に理由のコメントあり |
| 影 | 使わない | 厚みは `--case-edge` の上辺の縁で出す |

`rounded-xl`・`rounded-full` のピル形ボタン・`shadow-*` は新しく使わない。

## 部品のルール

| 部品 | ルール |
|---|---|
| 筐体 | 1画面の主操作を1つにまとめる面。`bg-surface rounded-2xl border border-hair border-t-case-edge p-3 sm:p-6`。1画面に1〜2個まで。筐体の中にさらに筐体やカードを入れない |
| 窓 | 読み取りの数字と指板だけを入れる暗い面。`bg-glass rounded-lg`。文章の段落を入れない |
| 読み取り | ラベル（`text-xs text-dim`）の下に数字（`font-mono text-3xl`、単位は `text-xs text-dim`）。主な数字1つだけ `text-accent` |
| 反応時間メーター | 0〜3秒の目盛り。1秒未満 `--correct`、2秒未満 `--accent`、それ以上 `--wrong` の帯と、今回の値の針 |
| セクションの区切り | 筐体の外は、見出し（`text-sm font-semibold text-ink`）と `border-t border-hair` の線で区切る。カードで囲まない |
| カードの並び | 使わない。選択肢の一覧（目標・レッスン・フェーズ）は、罫線で区切ったリストの行か、`bg-panel rounded-lg` の選択肢ボタンにする |
| ボタン | 主: `bg-accent text-bg font-semibold rounded-lg min-h-12`（1画面1つ）。副: `bg-panel text-ink border border-hair rounded-lg min-h-12`。文字リンク型: `text-dim hover:text-ink` |

### 選択肢の列数

フットスイッチを並べるグリッドの列数は、最長ラベルの表示幅（全角=2・半角=1）で決める。英語版の訳語も同じ規則で扱える。実装は `src/components/footSwitchGrid.ts` の `footSwitchGridClass`。

| 最長ラベル | 例 | スマホ | `sm` 以上 |
|---|---|---|---|
| 全角4文字以内（幅8以下） | 音名、度数、ローマ数字、トニック | 3列 | 4列 |
| 全角9文字以内（幅18以下） | サブドミナント、メジャー（明るい）、Dm7-G7-Cmaj7 | 2列 | 3列 |
| それより長い | 2本細い弦・2フレット上 | 1列 | 2列 |

列数は選択肢の数を超えない（2択を3列に置いて空きを作らない）。12音（`NoteSelector`）と度数（`IntervalSelector`）は全角4文字以内なので、それぞれの固定の並び（6列×2段など）のままにする。
決め方の根拠: 375px 幅の筐体の中で3列にすると1列の内側は約84px で、`text-sm`（14px）の全角が6文字までしか入らない。2列なら約134px で9文字まで入る。

## 実装上の注意

- 色は Tailwind のトークン名（`bg-surface` `text-dim` など）で指定し、`#` の色を直書きしない。例外は指板SVG（`boardPalette.ts` に集約）と、スケール・CAGED・度数などの音高の色分けデータだけ。音名の色（`NOTE_COLORS`）と度数の色（`INTERVAL_COLORS`）は `src/data/fretboard.ts` に置く
- Ant Design の `Segmented`・`Tabs` は `src/index.css` の上書きでこの文書に合わせる
- 例外として残した角丸・色には、その場で理由をコメントする
