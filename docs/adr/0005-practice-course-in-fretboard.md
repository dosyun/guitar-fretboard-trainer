# 0005 — 練習コースは指板トレーナーの中に置き、伴奏も指板トレーナーで鳴らす。ループ練習とはリンクだけでつなぐ

---
status: accepted
date: 2026-11-01
---

「今日は何を、どの順番で弾くか」まで決めた練習コース（[S5 仕様](../specs/2026-11-01-S5-practice-course.md)）を足す。1回の流れは「指板で構成音を確認 → 表示を消して探す → 伴奏に合わせて切り替える → つまずいた位置をもう一度 → ループ練習で自分の曲に当てる」で、2つのツール（指板トレーナー `/fretboard/`、ループ練習 `/looper/`）にまたがる。
コードを確かめると、伴奏に必要な部品は片方にしかない。指板トレーナーには Web Audio のシンセ（`src/data/audio.ts` の `playChord`）があり、コード音を鳴らせる。ループ練習には BPM・小節・コードの入力も、音を作る機能も無く、鳴らせるのは YouTube 動画か手元の音源ファイルだけである。また、ループ練習は URL のクエリを読まない。
そこで、**コースの①〜④（伴奏を含む）はすべて指板トレーナーの中で行い、ループ練習は改修せずに⑤のリンク先として使う**。伴奏はコード音とクリックだけの簡素なものにする。データの受け渡しはしない。

## Considered Options

- **A. 指板トレーナーの中で伴奏を鳴らし、ループ練習はリンクだけ（採用案）** — 既存の `playChord` に拍の予約を足すだけで③が作れる。ループ練習は無改修。代わりに、ループ練習の役割は「自分の曲で試す任意の一歩」にとどまり、2つのツールが「つながっている」感覚は弱い。
- **B. ループ練習に「コード進行の伴奏」を作る機能を足し、③をループ練習で行う** — ループ練習が「伴奏つきのループ」になり、2ツールの役割分担ははっきりする。ただしループ練習には音を作る仕組みが無く（旧版の譜面再生は公開ビルドから外してある）、BPM・小節の概念から作ることになる。練習の途中でツールを行き来するため、1回15分の流れが切れる。検証の前に入れるには大きい。
- **C. 指板トレーナーで「フレーズ（押さえる位置の並び）」を保存し、ループ練習が読み込む** — 運営者の元の案にある「保存したフレーズを Looper で練習する」に近い。しかしループ練習は受け取ったフレーズを鳴らせない（B が前提になる）。また同じドメインなので localStorage は共有できるが、指板トレーナーから `guitar-player.phrases.v1` に書くとループ練習の保存データを壊すおそれがある。B と合わせてでなければ意味が無い。

## Consequences

- 指板トレーナーに、拍を予約して鳴らす小さな仕組み（クリックとコード音）が入る。ガイド音モードの固定タイマーも、後でこれに載せ替えられる。
- コースの入口 `/fretboard/course/` を、耳トレ（`/fretboard/ear-training/`）と同じ「pathname で初期画面を決める」方式で足す。クエリ `?day=` を読むのはこれが初めてになる。
- ループ練習への移動は `/looper/?from=course&day=N` のリンクで行い、GA4 の page_view（プロパティはハブと全ツールで1つ、ハブ ADR-0001）で数える。移動が多く、かつ「進行をそのまま渡したい」という声が出たら、B を別の ADR で検討する。
- ADR-0002（ロックしない）に従い、コースの回はどこからでも始められる。「次の回」は終えていない最初の回を示すだけにする。
- **収益化**: MVP は無料で、課金の仕組みを入れない。基礎ツールは無料のまま、段階的なコースや課題セットを買い切りにする案は、S5 の主指標（第1回を終えた人が7日以内に第2回を始める率）が目安を超えてから判断する。
- 自動採点（マイクで音を拾う）は入れない。③は「止まらず弾けた／止まった」の自己申告で、測れるのは②のタップの正誤と時間だけになる。
