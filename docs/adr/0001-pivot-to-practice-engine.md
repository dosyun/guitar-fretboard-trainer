# 0001 — ビューア中心から練習エンジンへの戦略転換

---
status: accepted
---

これまで機能を横に足してきた（指板マップ/スケール/CAGED/ボイシング/オープン/ダイアトニック/アルペジオ＝9タブ中7つが「見るだけ」）が、それは便利な理論ビューアにはなっても、上達実感・継続・反射化を生まない。
そこで方針を転換し、**1問ごとの回答（回答時間を含む）を記録し、弱点を可視化し、次の出題を適応的に最適化する「練習エンジン」**を中核に据える。当面、新しい「見える」コンテンツ（新スケール・新コード表示）の追加は凍結し、計測→可視化→適応出題の土台に集中する。

## Considered Options

- **このまま機能を横展開**（新スケール、950スケール対応など）— 情報量が増えるだけで上達を保証しない。個人開発アプリではUXが壊れやすい。却下。
- **ビューアのUI/UX磨きを優先** — 見た目は最速で良くなるが「上達を保証する構造」が後回しになる。却下。

## Consequences

- 数ヶ月は回答ログ・計測・適応という「地味で不可視」な土台作りが中心になり、見た目の新機能は増えにくい。
- 既存7つのリファレンス表示は、練習エンジンを主役とした上での「脇役」に再配置される（[[0003]] のナビ再編につながる）。
